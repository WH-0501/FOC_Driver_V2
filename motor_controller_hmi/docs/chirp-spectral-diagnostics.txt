Chirp 原始录波诊断与邻频平均

入口：扫频窗口 → Chirp 离线分析。载入完整 *.samples.csv。
1. 周期一致性：保留原始三个周期 Y/X、周期残差和原始 H1。
2. 尖峰位置：固定 |Iq| >0.2 A 作为观察标记。连续点合并为事件；点击事件查看前后各 20 点原始给定和反馈，共用电流纵轴。此值不是保护阈值，不会删点、替换样本或修改控制。
3. 逐频点数据：新增尖峰谱线 RMS 和周期残差谱线 RMS。尖峰序列仅用于线性分解：标记点保留原值，其他位置设零；原始 H1 始终使用全部原值。这一分量与其他样本有交叉项，其谱线幅值不能解释为独立噪声功率占比。
4. 邻频原始谱平均默认关闭。选 ±5/10/20/40 Hz 后点击重新分析，得到单独的诊断曲线。对三周期及频带内所有原始复互谱/自谱求和，然后计算 H1=sum(conj(X)*Y)/sum(|X|²)，相干性=|sum(conj(X)*Y)|²/[sum(|X|²)*sum(|Y|²)]。不平均 dB、不先平均周期后虚增相干性，不剔除低相干谱线。
5. 频带必须对称，半宽不超过中心频率的 5%，且不超出录波频点范围。前两个基准点保持原始单谱线。实际频带和谱线数均显示、导出。谱线数不是独立测量周期数；真实平均周期始终为 3。
6. 邻频曲线保持原始 0.9 相干性门槛，仅作诊断，不替代原始带宽，也不自动输出平滑后带宽。窄峰、陷波和快速相位变化可能被平均，应结合原始值和多个半宽检查。无效点不连接。
7. 导出对比生成 .chirp-analysis.csv、.txt、.spikes.csv。所有诊断列明确标识，不覆盖原始录波。零相位滤波仍为可选独立对比。

run 38909 的复核结果
80000 点完整；三个用于分析的周期中有 106 个 |Iq| >0.2 A 点，均为单点事件（采样间隔 50 μs，不等同于模拟脉冲宽度）。这些点占反馈平方和约 11.19%；在其对应时刻的周期残差平方和占全部残差约 13.22%。尖峰未集中在周期边界。
周期残差 RMS：24.609 mA；600～2000 Hz 内约 9.129 mA，超过 2000 Hz 至 Nyquist 约 22.700 mA。分频带 RMS 不可直接相加；周期残差包括噪声、扰动和非平稳变化。
±10 Hz 对比：431 Hz 相干性 0.806→0.906，796 Hz 0.891→0.880，1082 Hz 0.818→0.795，1471 Hz 0.953→0.745。因此邻频平均不足以恢复可靠首次 -3 dB 交点，不输出替代带宽。
历史逐频录波 run 22913 可载入对照，复算带宽约 1321.44 Hz；并未核验本次与历史 PID、固件和工况一致，不能当作本次真值。
当前数据仅有给定和 Iq，不能从尖峰形状确定三相 ADC、PWM 采样、电角度或真实电流扰动的具体责任。
