# 纵轴刻度与阶跃分析修复

实时示波器增加数值纵轴与通道/单位标识。通过波形下方的“纵轴刻度”选择对应通道；该通道隐藏或没有有效数据时自动显示第一个有数据的可见通道。目标与对应反馈同时显示时共用量程，其余通道仍独立缩放，避免将不同单位误读为同一纵轴。

数据分析默认启用“从目标曲线检测全部阶跃”，默认分析完整记录，避免阶跃滑出实时视窗后无法分析。选择 Iq、速度或位置即可；选择对应目标通道也会分析其反馈。需要分析早先阶跃时，使用示波器 T1/T2 截取包含基线和响应的区间，再选择“示波器当前窗口 / T1-T2 / 触发捕获”。

自动模式读取已记录目标值，不再使用手动输入框的默认 1.0000。支持正负方向及回零阶跃，阶跃时间以目标发生变化的样本为准；目标值仅代表上位机提交，不代表设备执行确认。首次发送之前目标未知时，使用前面的实测基线。没有目标历史时需取消自动模式，输入与通道单位一致的手动目标；此时阶跃时刻是响应的 10% 交点估计。

结果包含阶跃时刻、基线、目标、幅值、稳态值/误差、10–90% 上升时间、超调及稳定时间。上升/超调使用 5 点因果中值滤波抑制单点尖峰；稳定时间用原始数据的 ±2% 幅值带，并要求末尾连续保持至少 5 点且持续时间达到响应窗的 5%。噪声超带可能使结果显示未稳定，这不等同于未检测到阶跃。未达到 90%、样本不足、没有目标变化、时间不连续等情况均有明确提示。

完整记录在点击时生成快照，计算在后台执行，不持续分析或发送设备指令。反复阶跃逐条列出并在下一次指令前分段，点击行查看详情；连续斜坡/正弦目标不应解释为单次阶跃响应。

验证包含正负一阶响应（理论上升时间 τ·ln(9)）、噪声尖峰、最近一次回零阶跃、目标通道映射、无响应、无阶跃、缺失数据和采样中断。
