# S01 低侧电流采样窗口设计与实施

日期：2026-10-24。基线：`4262a75071e993193a689ab7837053a36066cc5c`。

## 修改结论

采用固定三相低侧窗口方案：在定时器峰值附近预留三相下管同时导通的时间，将整个 ADC2 注入序列放入该窗口。通过电压矢量等比例限幅和公共占空比偏移约束最大高侧占空比，保持线电压方向和比例，不采用三相独立硬截断。

此实现针对系统分析文档的 S01。S02 的 PWM 预装载、S03 的独立新样本零偏累计、C01 的矢量抗饱和反馈和其他保护问题仍需分别整改。本修改也修正了零偏准备时的低侧导通设置，因为该设置是低侧采样成立的必要条件。

## 理论和经典实现的对应关系

MP6540 的 SO 信号来自低侧 MOSFET 电流，PWM 高对应高侧导通；高侧导通时不能把 SO 值无条件解释为相电流。[MPS 官方数据手册第 11 页](https://www.monolithicpower.com/en/documentview/productdocument/index/version/2/document_type/Datasheet/lang/en/sku/MP6540/)

SimpleFOC 的低侧采样将 ADC 与共同低侧导通区同步，这是本次固定窗口方案的参考。[SimpleFOC 低侧采样说明](https://docs.simplefoc.com/low_side_current_sense)

ST 的三电阻方案进一步根据扇区及窗口安排采样点和可观测相，适合在后续追求更高调制度时采用。本次没有直接移植其动态选相逻辑：当前 ADC2 是一个顺序转换器，已有三相去共模处理；动态两相重构需要同时调整触发、选相、有效标志及电流重构，不能只替换一个 SVPWM 函数。[ST UM1052 电流采样章节](https://www.st.com/resource/en/user_manual/um1052-stm32f-pmsm-singledual-foc-sdk-v43-stmicroelectronics.pdf)

## 时序预算

`project/Board/at32_foc_timing.h` 是本次增加的板级时序契约。TMR1 和 ADC 配置、FOC 周期宏以及 PWM 输出上限使用或检查该契约。

| 项目 | 默认值 |
| --- | --- |
| TMR1 时钟 | 180 MHz |
| PSC 寄存器 | 1，计数频率 90 MHz |
| ARR | 2249 |
| ADC 公共时钟 | HCLK/6，即 30 MHz |
| ADC 注入序列 | Ia、Ib、Ic、温度，共四次 |
| 单通道采样 | 13.5 ADC 周期 |
| 12 bit 转换 | 12.5 ADC 周期 |
| 触发预算 | 3 ADC 周期，包含同步裕量 |
| 完整序列预算 | 107 ADC 周期，321 个定时器 tick，约 3.567 μs |
| 每侧模拟建立和开关裕量 | 暂定 2 μs，即 180 tick |
| CH4 触发比较值 | 2088，上数触发 |
| 三相最大 CCR | 1908 |
| 最大占空比 | 1908/2249，约 84.84% |

转换时间采用器件资料中采样时间加 12.5 周期的定义。[AT32M412/416 数据手册 ADC 特性](https://atkap.arterytek.com/download/DS/DS_AT32M412_416_V2.01_ZH.pdf)

2 μs 是待板级确认的工程预算，不是已经测得的 SO 建立时间，也不是厂家保证值。应以实际 PCB 的 MOSFET 切换、SO 恢复、外部 RC、ADC 输入负载及温漂测量调整。增大 `AT32_FOC_CURRENT_SETTLING_NS` 会自动缩小可用占空比；不可能的配置在预处理时拒绝构建。

### 保证条件

对中心对齐、有效高 PWM A，以一个周期开始时 CNT=0 的上数时间轴表示：

```text
三相最后一个下管开始导通：t = max(CCRa, CCRb, CCRc)
ADC 开始触发：              t = trigger
ADC 序列预算结束：          t = trigger + sequence_ticks
三相最早一个下管关断：      t = 2×ARR - max(CCRa, CCRb, CCRc)

要求：trigger - maxCCR >= settling_ticks
      2×ARR - maxCCR - trigger - sequence_ticks >= settling_ticks
```

默认配置为：

```text
ADC trigger = 2249 - ceil(321/2) = 2088
maxCCR      = 2088 - 180 = 1908
触发前裕量 = 2088 - 1908 = 180 tick
结束后裕量 = 4498 - 1908 - 2088 - 321 = 181 tick
共同低侧窗口 = 2×(2249-1908) = 682 tick ≈ 7.578 μs
```

这里保守地把温度转换也放在窗口内。电流排在温度之前，减少温度转换对电流采样时刻的延迟；温度仍保留在 ADC2，不改变现有外部温度硬件连接。

```mermaid
flowchart LR
    A[上数到最大 CCR] --> B[建立裕量 180 tick]
    B --> C[CH4 触发 2088]
    C --> D[Ia Ib Ic 温度 转换预算 321 tick]
    D --> E[结束裕量至少 180 tick]
    E --> F[下数到最大 CCR]
```

## 调制方法

设 `dmax` 为板级允许最大高侧占空比。原线性圆 `Vbus/√3` 缩小为：

```text
Vlimit = dmax × Vbus / √3
k = min(1, Vlimit / hypot(Ud, Uq))
(Ud_actual, Uq_actual) = k × (Ud, Uq)
```

实际计算先归一化再求模，避免大输入平方溢出。逆 Park 和逆 Clarke 后仍使用现有 min-max 零序注入，公共中心从 0.5 改为 `dmax/2`：

```text
common = (max(Ua,Ub,Uc) + min(Ua,Ub,Uc)) / 2
duty_i = dmax/2 + (Ui-common)/Vbus
```

公共偏移在两相相减时消失，因此保留线电压；等比例矢量限幅保留电压角度。CLAMP 只吸收浮点边界误差，不能作为主要限幅机制。

24 V 母线时，线性电压圆从约 13.86 V 降至约 11.76 V。与仍以 0.5 为中心、把三相限制在对称区间的方案相比，这种公共偏移减少了不必要的电压损失。代价是最大电压与高速能力下降，零序分配及共模波形改变。应重新检查饱和工况；本次没有声称已完成 C01 抗饱和整改。

## 边界行为

- CCR 换算使用 `duty × pwm_compare_top`，保持实际定时器周期缓存机制。`AT32_FOC_TIMER_ARR` 只参与时序配置和有效性校验，不直接替代换算依据。
- 缓存为零时，在实际时序通过校验后从 ARR 初始化；非零缓存与实际 ARR 不一致则拒绝输出。`board_init()` 可显式重新读取周期，但动态改变 PWM 频率仍需重新计算整个采样契约。
- `pwm_hw_max_duty()` 在验证时序和缓存一致后，以 `AT32_FOC_CURRENT_MAX_CCR / pwm_compare_top` 提供上限。STM32/GD32 的换算实现不因本次调整而改变。

- 板级拒绝超范围、NaN 或 Inf 占空比，并关闭三相 PWM 通道，返回 `ERR_PARAM`，不单独裁剪三相。
- 系统时钟、TMR1 ARR、PSC 或 CH4 比较值与契约不同，板级能力返回 0；FOC 锁存 `FAULT_CURRENT_SENSOR` 并失能。
- FOC 调制拒绝无效电压、角度或母线输入，锁存参数故障并失能。
- 零偏准备改为 EN 有效且 PWM=0，对应 MP6540 下管导通，不再使用接近 100% 高侧占空比。
- 保留现有母线回退逻辑、PI 算法和状态机，其他分析问题仍以原文档为准。
