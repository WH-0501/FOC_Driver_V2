CAN-FD 仲裁段 1Mbps，数据段 5Mbps

# 协议格式


| ID      | Count | Command | Data1~N | 协议填充 |
| ------- | ----- | ------- | ------- | ---- |
| Node ID | CNT   | CMD     | DATA    | 00   |


> 正常情况下，电机端仲裁段只会过滤三个 ID：0x00、自身 ID、IAP 的 0x7FF

- Node ID: CAN-FD ID 地址， **0x00 表示广播**
- CNT: 帧计数
- CMD: 功能码
- DATA: 有效数据域
- 协议填充: CAN-FD 数据长度为（0~8、12、16、20、24、32、48、64），数据长度不足时补充 0x00

## 协议定义

### 主机 → 从机（命令）


| CMD    | 应答        | 有效数据长度  | 说明                      | 备注                                                                                                                                |
| ------ | --------- | ------- | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `0x00` | 不应答       | 0       | 同步信号                    | 同步所有关节的周期上报时间。例：`00 00`                                                                                                           |
| `0x01` | 不应答       | 电机数 × 3 | id + 目标位置               | 数据 2 字节、大端，位置 Q7 格式。例：电机 1 设 30° → `00 01 01 0F 00`；电机 1、2 均 30° → `00 01 01 0F 00 02 0F 00`                                      |
| `0x02` | 不应答       | 电机数 × 3 | id + 目标速度               | DHA1：Q0（`short`），例 500 RPM → `00 02 02 01 F4`，-500 RPM → `00 02 02 FE 0C`。DHB1：减速端速度 Q7，例 40 RPM → `00 02 02 14 00`（以下速度格式同 DHB1） |
| `0x03` | 不应答       | 电机数 × 3 | id + 目标电流（力矩）           | Q0（`short`），单位 mA。例：600 mA → `00 03 03 02 58`                                                                                     |
| `0x12` | 不应答       | 电机数 × 5 | id + 目标位置 + 目标速度        | 例：位置 50°、速度 1000 RPM → `00 12 04 19 00 03 E8`                                                                                     |
| `0x13` | 不应答       | 电机数 × 5 | id + 目标位置 + 目标电流        | 例：位置 50°、电流 200 mA → `00 13 05 19 00 00 C8`                                                                                       |
| `0x23` | 不应答       | 电机数 × 5 | id + 目标速度 + 目标电流        | 例：速度 1000 RPM、电流 200 mA → `00 23 06 03 E8 00 C8`                                                                                  |
| `0x30` | 不应答       | 电机数 × 7 | id + 目标位置 + 目标速度 + 目标电流 | 单帧最多 8 个电机，超出采用多帧周期下发。第 1 帧：总帧数（1 B）+ 帧序号（1 B）+ 参数（n × 7 B）；第 N 帧同理。灵巧手：CANFD1 接 12 电机（10–21 号），CANFD2 接 9 电机（1–9 号）              |
| `0x39` | 应答 `0x39` | 0       | 异常复位                    | 过流等异常后强制关断、清除故障、清零给定与 PID 并回到 IDLE；应答 1 B：`1` 成功，`0` 失败。例：`00 39`                                                         |
| `0x40` | 不应答       | 1       | 使能                      | `0` 失能（`00 40 00`），`1` 使能（`00 40 01`）。未设模式时使能默认为 PP（当前默认上电使能）                                                                     |
| `0x41` | 不应答       | 1       | 控制模式                    | PP(0) / CSP(1) / CST(2) / HM(3) / CSV(4) / MIT(5)。须失能后设置；上电默认 PP。例 CSP：`00 41 01`                                                 |
| `0x42` | 应答 `0x47` | 6       | 设置位置环 PID               | 失能有效；P/I/D 各 2 字节 Q12。例 P=0.015、I=0.001、D=0：`00 42 00 3D 00 04 00 00`（上位机暂只需 KP/KI）                                               |
| `0x43` | 应答 `0x48` | 6       | 设置速度环 PID               | 失能有效；格式同 `0x42`。例：`00 43 00 3D 00 04 00 00`                                                                                       |
| `0x44` | 应答 `0x49` | 6       | 设置电流环 PID               | 失能有效；格式同 `0x42`。例：`00 44 00 3D 00 04 00 00`                                                                                       |
| `0x45` | 应答 `0x4A` | 4       | 设置刚度 / 阻尼               | 失能有效；刚度、阻尼各 2 字节 Q12。例 0.015 / 0.001：`00 45 00 3D 00 04`                                                                          |
| `0x46` | 应答 `0x4B` | 6       | 设置保护参数                  | 失能有效；过温、过流各 2 B；欠压、过压各 1 B。例：85℃、2 A、16 V、26 V → `00 46 00 55 07 D0 10 1A`                                                        |
| `0x47` | —         | 0       | 获取位置环 PID               | 例：`00 47`                                                                                                                         |
| `0x48` | —         | 0       | 获取速度环 PID               | 例：`00 48`                                                                                                                         |
| `0x49` | —         | 0       | 获取电流环 PID               | 例：`00 49`                                                                                                                         |
| `0x4A` | —         | 0       | 获取刚度 / 阻尼               | 例：`00 4A`                                                                                                                         |
| `0x4B` | —         | 0       | 获取保护参数                  | 例：`00 4B`                                                                                                                         |
| `0x4C` | —         | 2       | 设置 Node ID              | 保存后可用。例如，设置 Node ID 为 2：`00 4C 00 02                                                                                              |
| `0x4D` | —         | 0       | 保存设置                    | 失能有效；写入用户区。例：`00 4D`                                                                                                              |
| `0x4E` | —         | 0       | 恢复出厂设置                  | 失能有效；出厂区拷贝至用户区。例：`00 4E`                                                                                                          |
| `0x4F` | 应答 `0x4F` | 0       | 清除锁存故障                  | 清除 `fault.latched` 并回到 IDLE；应答 1 B：`1` 成功，`0` 无锁存故障。例：`00 4F`                                                                     |
| `0x50` | 不应答       | 0       | 设置原点                    | 失能有效；当前位置设为零点。例：`00 50`                                                                                                           |
| `0x52` | —         | 0       | 获取电机类型                  | 例：`00 52`（当前 A1 电机不适用）                                                                                                            |
| `0x7F` | 不应答       | 2       | 周期上报频率                  | 0~1000 Hz，超 1000 无效，`0` 停止；上电默认 1000 Hz。停止：`00 7F 00 00`；500 Hz：`00 7F 01 F4`；1000 Hz：`00 7F 03 E8`；`00 7F 03 E9` 无效              |
| `0xAB` | —         | 0       | 电角度对齐                   | 失能有效。例：`00 AB`                                                                                                                    |
| `0xAC` | —         | 2       | MCU 温度校准                | 失能有效；单位 0.01℃。例：`00 AC 11 EF` 表示当前温度标定为 45.91℃，此后以此为基准                                                                            |


> **说明：** `0x42`~`0x46` 设置指令的从机应答 CMD 与对应获取指令（`0x47`~`0x4B`）一致。

# IAP

考虑到单总线多个电机升级情况，升级包数据段帧采样广播指令进行升级（当然，也兼容支持指定 node id 升级特定设备）。

## 数据帧格式

单电机升级IAP ID：Node-ID

统一升级IAP ID：0x7FF


| IAP ID | Data0 | Data1 | Data2-N |
| ------ | ----- | ----- | ------- |
| ID     | CNT   | CMD   | DATA    |




## 主机 -> 从机 IAP协议帧


| **CMD功能码**        | **Data LEN** | **说明**          | **备注**                                                   |
| ----------------- | ------------ | --------------- | -------------------------------------------------------- |
| 0xF8（不应答）         | 0            | 从 MCU 进入 IAP 模式 | IAP模式不再接收控制帧，且电机驱动芯片不再输出                                 |
| 0xF9（应答cmd=0xFC） | >32          | 从 MCU 开始升级     | 发送固件第一帧（固件头（固件大小与CRC32）+数据）从机擦除Flash后应答当前升级状态（cmd=0xFC） |
| 0xFA（不应答）         | x            | 从 MCU 升级数据      | 填充字节使用0xFF代替                                             |
| 0xFB（不应答）         | 0            | 从 MCU 结束升级      |                                                          |
| 0xFC              | 0            | 从 MCU 升级状态      | 当从机产生错误时自动上报，返回错误停止升级                                    |
| 0xFD              | 0            | 从 MCU 固件版本      |                                                          |
| 0xFE（不应答）         | 0            | 从 MCU 验证固件      | CRC32是校验和取反                                              |
| 0xFF（不应答）         | 0            | 从 MCU 复位        |                                                          |
