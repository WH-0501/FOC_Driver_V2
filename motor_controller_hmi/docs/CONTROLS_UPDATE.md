# 异常复位、纵轴缩放与清除记录

- 顶栏“异常复位”：单播当前节点 0x39，与旧版一致。停止本机自动运动任务，撤销该节点待处理运动/模式操作，等待专用应答；成功不弹提示，失败沿用错误栏。断开或升级时不可点击，不自动使能。此按钮不同于参数页的“清除锁存故障”。
- 在纵轴刻度区域滚轮，或图内 Ctrl+滚轮：以鼠标高度为中心同步缩放所有可见波形，各通道以相同比例围绕鼠标高度缩放；目标/反馈共享量程且每组只缩放一次。缩放 Y 不停止时间滚动。图内普通滚轮保留时间缩放，“重置视图”恢复自动量程。仅适用于时域波形。
- “清除波形 / 数据”：清空内存历史、触发/故障抓拍、光标、缩放和分析结果，包括暂停显示时的缓存。取消在途历史导出，旧的后台阶跃分析结果不再回填。连接、采集、当前设备状态不变，后续样本继续记录；已保存文件及归档不删除。

回归测试覆盖 Ctrl+滚轮图像变化且时间窗口不变、重置还原、普通滚轮时间缩放、暂停显示下清除、Demo 复位后不重新使能。未向真实设备发送控制指令。
