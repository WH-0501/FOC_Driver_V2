扫频界面与频率标识（2026-11-26）

设置区
起始频率、结束频率、幅值、频点数、反馈滤波对照、LPF 截止集中在一行。
每个标签固定在对应输入框上方，单位明确；滤波对照仅适用于 Chirp。
逐频模式沿用原始反馈，滤波控件禁用；已有 Chirp 滤波选择会保留。

图表区
默认并排显示录波与幅频/相频/相干性曲线。
右上“图表显示”可选择仅录波或仅频响，放大到整个图表区宽度。
切换布局不重置录波的时间缩放和位置。
“测量说明与诊断”和“频点数据”默认折叠，点击展开。
展开数据表后，可以拖动上下分隔线分配图表与表格高度。
测量状态、失败提示、原始带宽结果和录波完整性始终在主界面显示。
完整诊断信息保留在折叠区及导出说明中。

标识线
黄色 f_bandwidth：原始 H1 相对前两个有效、平坦低频点均值下降 3 dB 的首次交点。
与既有带宽数值共享同一个计算结果，使用对数频率插值，原带宽判定逻辑不变。
紫色 fc：原始闭环 H1 的 0 dB 向下交点，相邻有效频点插值后检查交点 >=100 Hz。
不跨低频基准到高频区的空档，不跨无效点；缺口后仍搜索有效相邻线段，但标注 fc 候选、首次未确认。
允许 93–126 Hz 等跨越 100 Hz 的有效区间；支持端点为零，整段全零不制造交点。
这是参考实现中的闭环 0 dB 诊断标记，不是开环增益穿越频率，不用于计算相位裕度。
fc 与 LPF 截止频率不是同一个量。
两条标识贯穿幅频、相频和相干性面板；图上方列出对应数值和定义。
主扫频窗口与 Chirp 离线分析都使用原始 H1 标记，滤波/邻频/逐周期曲线不替代它。

本次仅修改上位机显示及共享的带宽结果接口，固件、CAN-FD 协议和测量数据不变。
