# 电机参数辨识操作说明

本功能位于 Qt 版 MotorTune 的“配置与标定”→“参数辨识 · Rs / Ld / Lq / 磁链”。使用支持 0xC0、0xC1、0xC2 的新版 V2 固件，选择单个 Node。旧版 Python GUI 未同步此功能。

## 操作流程

1. 连接并选择节点，完成电流零偏校准和电角对齐，使电机处于失能且无故障状态。
2. 打开辨识窗口。窗口读取电角对齐和辨识状态；只有收到有效专用应答、遥测新鲜且节点一致时才允许启动。
3. 选择完整流程、仅 Rs/Ld/Lq 或仅磁链，设置下表参数。磁链辨识会驱动电机旋转，需空载自由旋转。确认测试参数符合电机能力后勾选确认框。
4. 点击“启动辨识”。进度显示已完成阶段数及设备累计耗时，不代表线性的剩余时间估计。可随时请求“停止辨识”，收到取消状态后才显示已取消。
5. 完成后检查结果，点击“应用到 RAM”。收到 0xC2 成功应答且结果与本轮一致后，显示已应用。此步骤不会自动重整定正常运行的 PID。
6. 点击“保存到 Flash”。该操作保存设备当前全部配置，并非仅保存辨识字段；只有 0x4D 专用成功应答才显示保存完成。掉电保持应在实机重启后验证。

也可先辨识 Rs/Ld/Lq 并应用，再选择仅磁链模式。仅磁链模式依赖设备已应用的有效电阻、电感参数。

## 配置与单位

| 配置 | 初始值 | 校验 |
|---|---|---|
| 测试电流 | 0.300 A | 0.02–43.69 A，并受电流跳闸关系约束 |
| 电压上限 | 3.000 V | 0.05–65.535 V；还需满足实际母线电压裕量 |
| 注入峰值 | 0.200 V | 0.01 V 至电压上限 |
| 注入频率 | 200 Hz | 20–1000 Hz，匹配当前 20 kHz 控制周期固件 |
| 目标轴速 | 20.00 rad/s | 2–200 rad/s，电机机械轴角速度 |
| 电流跳闸 | 1.000 A | 至少为测试电流的 1.5 倍，最大 65.535 A |
| 轴速跳闸 | 30.00 rad/s | 至少为目标轴速的 1.25 倍，最大 300 rad/s |

初始值仅供配置起点，不是电机额定能力。界面范围表示协议和算法边界，实际测试值应依据电机、驱动器及供电条件设置。

结果显示 Rs（Ω）、Ld/Lq（mH）、永磁磁链 ψf（Wb）。Ls 为 `(Ld + Lq) / 2` 的参考展示值，适合低凸极电机参考，不是额外的独立辨识量；设备实际应用 Ld 和 Lq。结果只在设备确认完成且相应有效位存在时显示。

## 状态与异常处理

- 窗口固定绑定打开时的 Node；切换所选节点不会重定向操作。启动、应用、保存要求节点仍一致。
- 只允许应用本窗口确认启动并完成的一轮结果。打开窗口时设备遗留结果可查看，不能直接应用。
- 通用 0x7E ACK 仅表示命令接收，不视为辨识完成、应用或保存成功。旧固件没有辨识专用应答时，查询超时且不允许启动。
- 查询或操作超时后，状态标为未知，停止自动轮询；检查通信后点击“重新查询”。停止请求不依赖遥测新鲜度。
- 辨识未结束时关闭窗口会请求停止及失能。通信断开无法确认停机，上位机不会显示已停止；需结合设备状态确认。
- `Ctrl+Shift+E` 可请求急停。辨识失败显示设备错误原因，失败和取消不会自动应用结果。
- 应用和保存均需新鲜的失能、无故障遥测。断开重连会作废本窗口之前的应用资格，需要重新辨识确认。

## 产线、Demo 与验证

产线向导的电阻、电感步骤共用 Rs/Ld/Lq 辨识窗口，磁链步骤打开仅磁链模式；设备确认应用成功后才推进。仍缺少固件接口的其他标定步骤维持原有阻止行为。

Demo 使用同一组辨识命令和应答格式，模拟阶段变化及应用/保存流程；窗口与保存结果均标明模拟，不能用作真实电机参数或掉电保持的证明。

新增 `identification_tests` 覆盖线格式与非法结果、完整启动→完成→应用→保存、停止抢占未完成的启动请求、关闭失能、旧固件 ACK、错误节点应答、保存失败、掉线及 V1/广播/过期遥测门禁。尚未完成真实电机辨识精度、CAN 停止延迟与 Flash 掉电保持的台架验收。
