# 三环 PID 调试

菜单“调试 → 运行模式 / 三环 PID 调试…”打开当前电机的独立非模态窗口。切换调试模式，勾选需要的环并应用，设备应答后才显示已确认。正常模式只关闭新增调试遥测，不改变电机使能、控制模式或PID。上电默认正常模式，调试配置不写Flash。原有周期波形报告继续运行。

每环独立一条64字节CAN-FD帧，不拆包。默认100Hz/环；单环最高1000Hz，双环各500Hz，三环各333Hz，总调试上限1000帧/秒。该上限只针对调试流，普通波形及应答额外占用带宽。主循环采样、发送忙和总线负载会降低实际频率；不补发积压样本。控制指令应答优先。UI刷新10Hz，保留每环最新10000条记录并可导出CSV，三环曲线叠加在共同时间轴，右侧勾选字段并查看最新值。绘图使用每环保留的记录，实时跟随窗口默认6秒；勾选“冻结显示”或手动缩放/平移后，冻结曲线和右侧数值快照，后台继续采集；冻结时可切换曲线，导出CSV使用冻结快照。点击“实时跟随 / 重置视图”恢复自动范围。图表随窗口缩放，左右分隔条可调整图表与选择面板宽度。

窗口每秒续租，关闭窗口发送退出命令。设备在主循环正常轮询条件下约3秒无续租自动退出；IAP期间停止调试。阻塞主循环的校准等操作会延迟此处理。窗口绑定打开时的Node-ID，主窗口改Node-ID不会将旧窗口的请求改发给另一台电机。通信失败或旧固件无应答时不显示已成功切换。

## 协议

均保留既有CNT、CMD两字节帧头。配置命令0xB8仅允许单播。

请求载荷：版本u8=1、环掩码u8（bit0电流/bit1速度/bit2位置；0正常模式）、每环频率u16大端。应答载荷：版本u8=1、error_t u8、已应用掩码u8、已应用频率u16大端。无效参数保持原配置，返回ERR_PARAM。

0xB9电流、0xBA速度、0xBB位置，各自载荷62字节：版本u8=1、flags u8、PID最近更新时刻u32大端（设备us），随后14个IEEE754 float32大端。完整CAN-FD长度恰好64字节。

flags：bit0该环在当前运行模式执行，bit1配置了输出斜坡，bit2设备处于故障状态。没有执行的环其PID值可能是旧值，不能当成实时闭环响应。设备更新时刻采用现有PID时间源，可能回绕或异常，不在上位机假装修复；图表横轴使用适配器逐帧接收时间的相对秒数，两者含义不同。

| float索引 | 字段 | 单位/含义 |
|---|---|---|
|0|reference|电流A；速度为关节rad/s；位置为关节rad|
|1|feedback|同reference|
|2|iq|实时Iq，A|
|3|id|实时Id，A|
|4|dt|PID本次积分步长，秒|
|5|integral|积分状态，含反饱和调整后的值；单位同PID输出|
|6|output|PID返回输出，电流V/速度A/位置rad/s；不代表后级调制或位置输出限幅后的最终值|
|7|vbus|滤波后的母线电压，V|
|8|shaft_speed|电机轴速度，rad/s|
|9|kp|该环配置比例增益|
|10|ki_config|固件配置Ki；只有电流环实际Ki需要乘10000|
|11|limit|PID输出限幅|
|12|i_limit|积分限幅；0禁用积分|
|13|ramp|每秒输出变化限制；0禁用斜坡|

error=reference-feedback、P项=kp×error由同一帧数据计算。电流环帧报告q轴PID状态，同时包含实时Id；不是两套d/q PID全量配置。没有传D项或完整故障位图。调试快照在短暂关闭中断期间复制，浮点编码与CAN发送在恢复中断后完成，不在FOC中断内发送。

## 当前慢响应排查

选择电流环、1000Hz。查看实际给定是否阶跃，dt是否符合真实控制周期，Ki配置是否约0.1508，积分限幅是否非零，ramp是否为零，再比较P项、积分状态、PID输出和母线电压。此功能适合定位几十毫秒问题，不能以1kHz抽样验收800Hz带宽或亚毫秒上升时间。实际硬件帧率及对控制中断的影响仍需上机验证。
