# 工程设计

## 已自动确定的技术选择

使用 C++20 + Qt 6 Widgets，QPainter 自绘波形；不引入 QML、QtCharts、OpenGL 驱动依赖。Qt 6 自适应 DPI。遵循指定 DESIGN.md 的 #07080a 背景、#101111 表面、克制红色危险操作、蓝色交互、边框层次、8px 间距体系；将营销页的大字号/留白转换为可工作的桌面仪器密度。

## 模块

| 模块 | 职责 |
|---|---|
| protocol | 纯编解码、单位归一为 rad/A/RPM、DLC、PID Q12、应答、ASIX 校验 |
| backend | CanBackend 接口、Demo、原生 64 位 ZLG/ControlCANFD、隔离兼容进程 |
| session | 单个 I/O 工作线程、命令队列、紧急标志、命令关联/超时、安全门禁、IAP 状态机 |
| sampling | 有界环形缓冲、独立触发捕获、故障前后窗口、统计、FFT、CSV |
| scope | 30 Hz UI 刷新、每像素 min/max 保留、缩放/框选/游标/XY/FFT |
| archive | SQLite 事务、SN 历史版本、唯一当前版本、测试记录、回读比较 |
| window/workflows | 原生视图、角色导航、操作确认、向导、测试、报告、只读扩展 |

Session 的 QObject 在 UI 线程，run() 中独占后端生命周期。UI 仅在短互斥段添加请求或读取快照。接收无逐样本 Qt 信号；只对低频应答和节点发现发信号。主环每次最多处理一个普通请求，紧急标志每轮优先检查。接收非阻塞，绘图不会阻塞设备接收。缓存满后覆盖最旧样本并显示计数，不默默扩容。

触发精度来自收到的每个样本时间，不来自 UI 重绘。原生 DLL 的 uint64 微秒时间先做整数差再转换 double，保留大时间戳的微秒精度。故障窗口为第一次故障边沿前 5s、后 5s；启动不足 5s 时只保留实际存在数据。

示波器每通道独立自适应纵轴，图例显示各自范围。XY 为等比例坐标。FFT 用 Hann coherent gain 校正单边峰值振幅，拒绝明显不等间隔样本。采样暂停冻结缓冲，恢复保留实际时间间隙。

## 状态和安全

连接期间协议版本固定。写参/改模式要求目标节点 750ms 内遥测显示已失能。使能要求无故障且 V2 模式非 IDLE；运动要求新鲜使能遥测。操作确认发生在原生界面；脚本只有数据快照，无 Session 指针或通道。

急停清普通请求、取消 IAP/实验，广播 0x40(0) 和 0x39，实际状态由遥测确认。禁止将 TX 成功、ACK 或估计状态替代硬件成功。厂商 DLL 调用时间仍由厂商实现决定，必须真机测量最坏延迟。

IAP 不与普通请求穿插；START/DATA 使用连续 CNT，末帧补 FF。收到 START 专用 FC 后才发送 DATA；擦除等待可到 120s，期间不发送状态查询以免影响固件；DATA 1ms 间隔；不重发可能已写 Flash 的帧。VERIFY 完成后 RESET，重新连接确认版本。

## 扩展边界

Python 进程执行的是 AST 白名单表达式语言，不是任意 Python eval/exec。仅提供标量运算、受限统计函数及快照索引。限制输入、AST 节点/深度、样本数、输出和执行时间。禁止属性、import、循环、文件/网络；插件 JSON 仅声明 snapshot.read。未来通用 Python 插件必须引入 OS 沙箱，不能把本进程方案声称为任意 Python 的安全沙箱。
