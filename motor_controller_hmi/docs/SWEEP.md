# 扫频 / 带宽测试

设备端快速多正弦与逐频模式已实现，详见 [DEVICE_FRA.md](DEVICE_FRA.md)。本文其余内容描述保留的主机低频测试与离线样本分析。

入口：数据分析 → 扫频 / 带宽测试。共享主窗口样式，独立测试窗口集中显示配置、进度、幅频/相频图和频点表；不会覆盖原来的阶跃结果或清空波形历史。

## 在线低频测试

- 当前节点需已使能 CST 模式，遥测有效，勾选空载和工作区安全确认。不会自动使能或切换模式。其他实验、自动测试、升级运行时不能打开。
- 起止频率 0.2–4 Hz，3–30 个对数频点，电流幅值 0.005–0.5 A。
- 20 ms 定时发送正弦电流；使用实际经过时间计算相位，不补发定时器停顿期间的指令。调度停顿超过 150 ms 中止。
- 每频点前 2 周期用于稳定，后 5 周期用于分析。低频测试耗时较长，例如 0.2 Hz 单点 35 秒。
- 从目标事件记录重建实际已提交的阶梯给定，与同一主机时钟下的 Iq 接收时间配对。结果包含排队、通信和返回延迟，是端到端低频频响，不能当作设备电流环带宽。
- 当前节点变化、连接/遥测失效、升级、故障、失能、模式变化、取消安全确认、有效温度达到 60°C，均中止；完成、停止、关窗均停止发送并请求清零失能。已有设备保护保持生效。
- 在 PID 调试上报模式下，常规反馈可能只有低频状态帧，质量检查会拒绝采样不足的频点；在线测试建议切回正常遥测并使用足够采样率。

## 高频设备数据导入

支持逐频点稳态记录，CSV 必须具有如下表头：

```csv
frequency_hz,time_s,input,output
10,0.000,0.000,0.000
```

每个频点至少 32 点、3 个周期；输入和输出必须同单位、同一采样时钟。导入前去除切频过渡段。文件最多 200 个频点 / 200 万点。不支持直接把连续 chirp 数据标成逐频点数据，也不能混用主机目标时间和设备反馈时间。

高频激励必须由设备或外部同步信号源生成。设备端高速辨识协议及使用方法见 DEVICE_FRA.md；开发验证未自动执行真机动作。

## 计算与判定

对每个频点分别拟合 `a sin(2πft)+b cos(2πft)+c`，常数项去除偏置。幅值取 `sqrt(a²+b²)`；增益为 `20log10(反馈幅值/输入幅值)`；相位为反馈减输入的相位，显示 −180° 至 180° 主值。使用真实时间，不要求严格等间隔。

检查有限数值、时间单调、不同时间点每周期至少 10 点、最大间隔不超过 0.2 周期。输入拟合 R² ≥ 0.90。反馈不再用 R² ≥ 0.80 一刀切：至少 3 个完整周期分别拟合传递幅相，相对全窗结果的幅值 RMS 偏差 ≤15%、相位 RMS 偏差 ≤10°；可分辨的 2–7 次谐波幅值平方和开方不得超过基波的 25%。未通过的频点保留原因，不参与带宽计算。反馈 R² <0.80 但重复性与谐波检查通过时，保留结果并标记噪声较大。这些是工程质量门限，不是统计置信区间。R² 是正弦拟合优度，不是频域相干函数；有明显噪声/谐波时需要提高信噪比或重新采样。

带宽基准是最前两个有效频点的 dB 均值，两点差不得超过 0.5 dB。需要至少三个频点；以第一处相对基准下降 3 dB 的相邻频点作对数频率插值，并显示交点所在区间。不会跨越无效频点、外推未测频段，或将单点增益直接称为带宽。需确认起始频段确为低频平台；仅两点平坦不能证明覆盖真实直流平台。闭环频响不用于推算开环增益裕度/相位裕度。

导出产生频响 CSV、`.samples.csv` 原始配对稳态样本及 `.txt` 来源/带宽说明。原始样本可再次导入复核。关窗前请导出需保留的测试结果。

## 验证

自动测试覆盖已知一阶低通的幅值/相位、−3 dB 交点区间、无交点、无输入、噪声、短记录、时钟回退，以及 Demo 测试关窗停止下发并失能。不以软件仿真结果代替真机带宽测量。
