电流环扫频：请求频段与基准平台（2026-11-27）

使用方法
1. 完整带宽测量：设置覆盖低频平台到衰减区间的起止频率。仅在本次原始 H1 支持低频平台且存在连续有效的 −3 dB 交点时报告带宽。
2. 局部频响复测：例如 600–1500 Hz，设备严格按请求频段激励，不补入 20/40 Hz。逐频正弦仍按整数采样周期量化实际频率，例如 20 kHz 下请求 600 Hz 实际为 606.061 Hz。
3. 局部复测显示原始幅频、相频、相干性，允许离线对照；不借用历史基准，不报告绝对带宽或首次 fc。选择用途不会改变 H1 数值。
4. 当前仅支持电流环 CST / Iq。既有 20–2000 Hz 输入限制保留；本次没有开放速度环、位置环或低于 20 Hz 的激励。

低频平台规则（电流环给定到反馈、同单位）
从第一个频点开始，不能跳过无效点寻找一段看起来平坦的数据。
平台位于起点的 3 倍频率范围内，至少连续 3 个有效点，频率跨度至少 1.5 倍，相邻频率比不超过 2。
原始 H1 的相干性仍要求 γ²≥0.9；平台幅值极差≤0.5 dB，主值相位绝对值≤15°，各点增益绝对值≤1 dB。
以上是当前单位增益电流跟踪的保守资格检查，不是任意对象的普适 DC 增益证明，也不适用于直接套用开环或异单位传递函数。
基准取合格平台增益 dB 的中位数。显示实际使用的频率范围、点数和基准值。
随后沿连续有效原始 H1 点寻找首次低于基准 −3 dB 的交点，沿对数频率插值。无效点或频率比大于 2 的未测间隙阻止确认；不会外推或跨缺口补线确认。
未形成平台时提示降低起点、增加所需频点或选择局部复测；不得将衰减区前两点直接当作 DC 基准。
原始 H1、逐周期对照、Welch/CSD、16 点均值和 LPF 对照保留。滤波结果不决定最终带宽。
固定 700–1300 Hz 加密保持已撤销状态。

通信兼容
CAN-FD 接口、命令号 0xBC/0xBD/0xBE/0xBF、原始样本帧及长度不变。
仅将现有时序/计划扩展版本升级为 AE/2、AD/2，表示按请求频段执行，无隐含低频锚点。
新上位机启动前拒绝不支持该能力的旧固件；新固件拒绝旧版启动回显。停止和状态查询仍可用。固件与上位机须配套更新。
测量用途为上位机元数据，不增加 CAN 字段。新录波格式 3 保存 full/local，用旧程序打开会拒绝而不是误用基准；新程序继续导入格式 1/2 历史录波，按完整测量重新检验平台。

本次固件配置
保留工作区原有 4000 ms 单周期、1 个稳定周期 + 3 个测量周期，共 16 s。20 kHz 时为 320000 点。
未改变周期配置、速度/行程保护开关的现值（均为 0），其他保护和阈值保持原值。未增加滤波、未搬到 SRAM、未向 motor_controller/test 添加代码。
逐频每点稳定至少 20 ms 且至少 4 个整周期，再采集 4 段 × 4 周期，时序保持原值。
APP 镜像 50312 字节，限制 55296 字节，余量 4984 字节；EFW 32 字节封装头不计入 APP。

验证与解释
真实 sweep_engine / sweep_chirp / sweep_protocol 源码的本地 C 探针通过：请求范围、逐频计划、完整点数、幅值边界、新旧版本拒绝、非有限数中止及停止命令。
上位机覆盖平台资格、相干性门槛、无效点/大间隙阻断、局部用途切换和录波元数据往返、设备时序窗口、模拟完整采集。没有运行实体电机测试。
使用 test1126-0.2A-{1,2,3}.csv.samples.csv 三份 80000 点完整历史录波验证，原始 H1 增益最大差为 0 dB，相位、相干性与有效标记保持一致。
新平台均为 20–50 Hz 四点，中位数约 −0.24 / −0.23 / −0.23 dB；相对平台带宽为 1053.23 / 1122.09 / 1085.93 Hz。
这些数值变化来自基准定义改变，不能据此宣称采样噪声已经消除或硬件精度得到提高。旧录波不能验证新固件从 600 Hz 起扫的现场运动和信噪比，需要新采集确认。
