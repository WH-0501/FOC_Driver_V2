# 电机轴硬限速与电流软限速

对外界面及协议使用输出轴 RPM；内部保护使用电机轴 rad/s，按减速比转换。

## 固件硬限速

`MAX_VELOCITY_RPM = 3000` 为电机轴固定绝对上限（阈值不可通过协议修改）。当 **硬超速保护已使能** 且编码器测得的 **电机轴** `shaft.velocity_rad_s` 换算 RPM 达到 3000，锁存 `FAULT_OVER_SPEED` 并立即 PWM 失能。B6 四字节扩展可关闭该保护（仅 RAM，默认开启）。与减速比无关：硬判断在电机轴；CAN 显示/设置软限速时使用 **输出轴 RPM = 电机轴 RPM / 减速比**。

这是基于编码器测速的固件超速保护，关断输出不等于机械轴瞬间停止；惯性和外力仍可能使转速超过阈值。其他电流、电压、温度故障保护继续生效。原有输出轴速度与电机轴默认阈值混用的故障判断已移除；硬超速统一按电机轴判断。`motion.max_speed_rad_s` 及位置环限幅数值保持原样，属于历史运动控制配置，不再承担电机硬超速保护。

## 电流模式软限速

默认 2700 RPM，GUI 运动控制页直接设置输出轴 0～60 RPM（当前减速比 50）；0 仅关闭软限速。参数只保存在 RAM，重启恢复默认，不随 Flash 保存。

设软限速为 L，轴速度为 w，用户 Iq 先经过现有电流幅值限制得到 I。只有 I 与 w 同号时削减加速电流：

- |w| ≤ 0.9L：Iq = I。
- 0.9L < |w| < L：Iq = I × (L − |w|)/(0.1L)。
- |w| ≥ L：Iq = 0。

I 与 w 反号时保留用户请求的制动电流，不主动增加反向制动。默认从 2430 RPM 开始削减。软限速设为 3000 时与硬保护没有阈值裕量；正常运行应设置低于硬上限的值。它是转矩削减机制，不是精确恒速控制器，外力拖动时仍可能触发硬保护。速度和位置模式不受这项软限速控制。

GUI 显示固定硬上限、电机轴转速、用户 Iq、限制后 Iq 和软限速介入状态；限制后 Iq 是电流环参考值，不是实测 Iq。运行中允许修改软限速，不修改用户原始 Iq 指令。

## CAN FD 接口

仅接受本节点单播，拒绝广播。B5 读取，无请求负载；B6 设置输出轴软限速，请求为大端 uint16 RPM。可选 **4 字节扩展**：后 2 字节为标志字，bit0=`1` 使能电机轴硬超速保护（3000 RPM 锁存故障），bit0=`0` 关闭；仅 2 字节时只改软限速、不改变硬保护开关。输出轴 RPM 乘减速比换算电机轴后大于 3000 RPM 或不足 2 字节的请求返回参数错误。

应答负载 20 字节，大端 `>BBHHBBiii`：**版本 3**（版本 2 仍兼容，硬保护状态视为始终开启）、错误码、输出轴硬上限 RPM、输出轴软限速 RPM、控制模式、**状态字节**（bit0 软限速介入，bit1 硬超速保护已使能）、输出轴速度(milli-RPM)、用户 Iq(mA)、限制后 Iq(mA)。

## 验证与上机检查

主机回归覆盖正反向硬限速、模式独立停机、故障锁存、软限速渐减、保留制动电流、关闭软限速仍保留硬保护，以及 GUI 协议解析和设置确认。ARM 编译验证不能替代真实电机试验。

先在低软限速下观察用户 Iq 与限制后 Iq，确认正反向趋近限速时加速电流下降，反向电流仍可制动；然后确认重新上电恢复 2700 RPM。硬保护应使用受控的测速注入或试验台验证，不能仅凭空载高速测试推断机械安全。

## 代码组织

硬超速检测集中在 `foc_fault.c` 的 `motor_fault_check_shaft_speed()`，由控制中断与轮询共用；`foc_fault.h` 只声明接口。已移除 `speed_limits.h`，不新增 `.c` 模块。纯软限速计算保留在 `speed_limit_math.h`。

## 对外速度单位更新

GUI 与新增限速接口统一为输出轴 RPM，内部保留电机轴 rad/s。换算：电机轴 RPM = 输出轴 RPM × 配置减速比。当前减速比 50，硬上限显示 60 RPM，默认软限速 54 RPM；输入 20 RPM 在固件中转换为电机轴 1000 RPM。GUI 实际上限以设备回读为准。

为防止旧版 GUI/固件把两种轴单位混用，限速命令改为 B5（读取）、B6（设置），应答版本为 2；旧 B3/B4 不再处理。请求仍为 uint16 整数 RPM，应答硬/软阈值改为输出轴整数 RPM（向下取整），速度为输出轴 milli-RPM，电流字段不变。旧 GUI 与新固件、新 GUI 与旧固件均不能设置限速，必须配套更新。上文 B3/B4 与轴端协议描述为历史版本，以本节为准。
