# 阶跃列表与逐条详情

分析页面的自动模式现在列出所选记录内的全部目标变化，而不是只返回最后一次回零。点击“阶跃响应”生成记录快照，列表默认选中第一条，点击任何行可查看该条完整 JSON 详情；列表和详情之间可以拖动分隔条调整高度。

每条分析在下一次目标变化前结束，基线不跨越上一条目标变化。无足够基线、后段不足、无响应、没有达到 90%、采样中断等情况仍保留列表行并给出原因；“未稳定”与“未找到阶跃”不同。

列表包含来源、阶跃时刻、原指令、目标、实际初值、首次 10–90% 时间、保持交越时间、10%/90% 时刻与阈值、原始峰值超调、观察窗和状态。位置单位 rad，速度 RPM，电流 A，与所选分析通道一致。未知原指令和不可测指标显示“—”，不填零。

首次交越使用原始采样，可能被尖峰提前触发；保持交越要求连续达到阈值指定时间，默认 2 ms，可调整。时刻记录保持段起点，不额外把保持时长加到测量值。详情中原有 rise_seconds / overshoot_percent 继续表示 5 点中值滤波后的指标；first_rise_ms / raw_overshoot_percent 是原始数据指标，qualified_rise_ms 是保持交越指标。

“导出分析”同时保存选中条目的详情和全部阶跃记录。分析只读取主机采样快照，不发送任何 CAN 指令。目标记录仍是主机提交值，不表示设备执行确认。

验证：四次连续目标变化（正阶跃、回零、负阶跃、回零）全部识别；修改后续响应不影响前一条结果；短响应保留无效行；界面选中不同列表行显示对应详情。沿用全部 CTest 回归组。
