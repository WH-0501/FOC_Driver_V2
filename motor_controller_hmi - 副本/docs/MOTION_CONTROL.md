# 实时示波页运动控制（2026-11-04）

目标给定和限速区位于右侧控制栏，采用纵向布局，与紧凑的两列实时反馈集中展示。右栏宽度 380 px；顶部实时状态使用与运动控制一致的边框卡片，常驻显示，并通过分隔线与下方控制区隔开。仅运动控制区独立滚动，底部链路提示也固定显示；限速说明默认收起，可点击展开。示波区域恢复完整的纵向空间。研发工作台各页均可使用，产线工作台隐藏手动控制。选择 TORQUE 后可编辑目标电流 Iq（A，0.001 A = 1 mA），点击发送才下发；支持电流归零。位置以 rad、输出轴速度以 RPM 输入，按 V1/V2 模式启用对应字段。MIT 支持组合目标，V1 CST 保留速度与电流组合给定。

所选模式必须与设备新鲜遥测一致，电机已使能、无故障且已勾选工作区安全才可发送。目标值可以在失能时编辑，编辑不会自动下发；自动测试、激励或升级占用期间禁止手动给定。发送前工作线程再次检查遥测、使能状态和预期模式。普通目标命令显示“已发送”，不把链路发送当作设备执行确认。

每次连接成功后仅自动发送一次 0xB5；后续只有点击“读取限速”才查询，不进行定时轮询或自动重试。切换页面、模式、节点均不额外查询。0xB6 仅点击“发送限速”时发送，编辑数值/勾选开关不会下发；B6 使用自身应答确认，不追加 B5。界面分别展示软限速开关/阈值、硬超速保护开关/固件只读阈值、软限速是否介入，以及设备回读的输出轴 RPM、用户 Iq、限制后 Iq。非电流控制时不把占位电流 0 当作限流结果。软限速 0 仅关闭软限速，不关闭硬保护。90% 阈值开始削减加速电流、保留制动电流；软/硬配置均为 RAM，允许运行中通过 0xB6 调整，重启恢复默认。

限速应答格式 2 和 3 必须包含完整 20 字节，允许 CAN FD 尾部填充。格式 2 的硬保护固定开启，不提供关闭开关；格式 3 根据回读状态位显示，并使用独立请求标志位写入。设备回读成功前禁止写入。回读结果带快照时间，标注“上次回读”和“回读时”，不会将历史介入状态冒充实时状态，也不再因 2 秒未查询而自动过期。首次读取失败时显示待确认；后续读取失败保留最近快照并提示本次失败；写入失败则清除确认状态，需手动读取。读取不会覆盖未发送的编辑值。切换节点/协议或重新连接会清除旧确认状态和目标草稿；切换节点后需手动读取，重连则自动读取一次。写入和运动命令仍要求新鲜遥测。

配置标定页可直接定位到右侧统一控制区，避免两处编辑器对设备状态产生不同解释。

自动验证：运动模式兼容矩阵、限速格式/符号/填充/错误应答、运行中修改限速、错误模式和错误目标通道拒绝、遥测过期门禁、目标发送/归零、未发送编辑保留、节点切换和 V1 CST 限流显示；另运行原有 core_tests、demo_smoke、extension_tests。所有运动测试均使用 Demo，尚需在安全台架上验证真实电机的响应和限速介入行为。未修改 motor_controller_gui。

按需查询回归验证：连接仅一个 B5；连续界面刷新与空闲不查询；重复点击合并在途请求且按钮不闪烁；编辑限速无 B6，点击发送恰好一个 B6 且不附加 B5；切换节点/模式不查询；重连只读一次；首次查询超时后跨过原 10 秒重试周期仍不自动重试。所有测试使用 Demo。
