# 目标值显示

实时示波增加目标位置（rad）、目标速度（RPM）、目标电流（A）三个可勾选通道，默认关闭，与旧版选择方式一致。目标曲线用虚线；同时选中对应反馈时，两条曲线共用量程。右侧常驻状态卡显示最后提交的三个目标数值。

数据来自 CAN 后端成功提交的指令，而非输入框编辑值，也不代表下位机确认执行。未发送的通道显示为未知，不画零值曲线。被安全检查拒绝或驱动发送失败的指令不更新目标值。缓存按节点隔离，重连清空；旧时间戳遥测不会被赋予后续发送的新目标。时间分辨率跟随遥测，目标变化从发送之后的遥测样本开始记录。

支持 V1/V2 的单目标、组合目标和多节点目标记录。V1 位置统一转换为 rad，电流统一为 A，数值采用线上 int16 量化后的值。

三个通道进入现有环形缓冲、像素峰值包络、触发捕获和 CSV 导出。CSV 保留原有 14 列顺序，在末尾增加 target_position_rad、target_velocity_rpm、target_current_A；未知值为空。每个样本增加三个 double，百万点原始样本约增加 24 MB，绘图仍按像素数聚合，不逐帧复制整段历史。

验证：CTest 8/8 通过，覆盖协议换算、多节点记录、未发送/被拒绝目标、重连、历史包络、CSV 列与界面勾选。12 通道全部显示，1200×650 离屏测试，百万点历史下 5 秒视窗平均 5.04 ms/帧，1000 秒全历史平均 13.75 ms/帧（本机测量，不等同于真机持续采集性能）。无真机控制指令或固件烧录。
